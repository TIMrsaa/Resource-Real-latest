# 학습 가이드 — 도구를 넘어 조직으로

## 문제 다시 보기 — 복잡성은 어디로 가나

46에서 정교한 플랫폼을 쌓았습니다. 관측·메시·보안·GitOps... 강력합니다. 하지만 질문:

```
이 복잡성을 누가 감당하나요?
  선택 A: 개발자가 다 배웁니다
    → 모든 개발자가 K8s·Istio·Prometheus·Crossplane 전문가?
    → 불가능. 개발자는 비즈니스 로직에 집중해야
  선택 B: 플랫폼 팀이 흡수합니다
    → 플랫폼 팀이 복잡성을 감추고, 개발자에겐 단순한 경로만
    → 이것이 플랫폼 엔지니어링
```

플랫폼 엔지니어링의 본질은 **인지 부하의 재배치**입니다 — 복잡성을 없애는 게 아니라(없앨 수 없습니다), 개발자에게서 플랫폼 팀으로 옮깁니다.

## Team Topologies — 이론적 뼈대

플랫폼 엔지니어링은 Team Topologies(팀 구조론)에 기반합니다:

```
스트림 정렬 팀(Stream-aligned): 제품·기능을 만드는 개발팀 (다수)
플랫폼 팀(Platform): 스트림 팀이 빠르게 흐르도록 셀프서비스 제공
활성화 팀(Enabling): 전문 지식으로 다른 팀을 돕는 (일시적)
난해한 하위시스템 팀(Complicated-subsystem): 특수 전문 영역

플랫폼 팀의 사명:
  스트림 팀의 인지 부하를 낮춰 흐름(flow)을 빠르게
  → 개발자가 인프라 걱정 없이 배포하도록
```

이 관점에서 41(Crossplane)·42(Backstage)·46(플랫폼)은 **도구**일 뿐이고, 진짜는 **플랫폼 팀이 개발자의 인지 부하를 흡수하는 조직 구조**입니다.

## 황금 경로 — 핵심 개념

```
황금 경로(Golden Path):
  "이 길로 가면 모든 게 준비돼 있다"는 잘 닦인 표준 경로
  예: "새 서비스 → Backstage 템플릿 → 레포·CI·DB·관측·배포 자동"
  → 개발자가 결정할 것을 줄이고(인지 부하↓), 모범 사례를 내장

★ pave, not fence (길을 닦되, 울타리 치지 마세요):
  황금 경로는 매력적이어야(쉽고 빠르니 자연히 선택)
  강제가 아니어야 (벗어날 정당한 이유가 있으면 벗어날 수 있게)
  강제하면 → 개발자가 우회(그림자 IT), 플랫폼 불신
```

41 lab-02(Composition), 42 lab-02(Template)에서 황금 경로의 메커니즘을 봤습니다. 이 모듈은 그것을 **어떻게 설계하고 조직에 안착시키나**를 다룹니다.

## 제품으로서의 플랫폼 — 가장 중요한 전환

42에서 "Backstage는 도구가 아니라 문화"를 배웠습니다. 그 문화의 핵심이 여기 있습니다:

```
플랫폼을 프로젝트로: 만들고 끝 → 낡고 안 씀 (42의 실패 사례)
플랫폼을 제품으로:
  내부 고객(개발자)이 있습니다
  그들의 니즈를 조사합니다
  채택률·만족도를 측정합니다
  피드백으로 개선합니다 (끝나지 않음)
  → 개발자가 "쓰고 싶은" 플랫폼
```

이 전환("우리가 만든 걸 써라" → "개발자가 원하는 걸 만든다")이 플랫폼 엔지니어링의 성패를 가릅니다. 도구(41·42·46)는 있어도 이 사고가 없으면 실패합니다.

## 측정 — 플랫폼이 성공했는지 어떻게 아나

```
플랫폼의 성공 지표:
  채택률: 개발자가 실제로 쓰나 (강제 아닌 자발)
  DORA(cicd 26): 배포 빈도·리드타임·MTTR·실패율 개선됐나
  인지 부하: 개발자 설문 (인프라에 쓰는 시간↓?)
  개발자 만족(DevEx): 플랫폼이 도움되나
  온보딩 시간: 신입이 첫 배포까지 걸리는 시간↓?

★ "플랫폼을 깔았다"가 아니라 "개발자 흐름이 빨라졌다"가 성공
  → 제품처럼 지표로 검증
```

## 이 모듈의 태도 — 겸손한 강력함

플랫폼 엔지니어링은 강력하지만 겸손해야 합니다:

- 플랫폼은 **개발자를 위한 것**이지 플랫폼 팀의 자기만족이 아닙니다
- 화려한 기술보다 **개발자가 실제로 쓰는** 단순한 것이 낫습니다
- 작은 조직엔 플랫폼 팀이 과할 수 있습니다(관리형으로 충분)
- 플랫폼은 끝나지 않는 **여정**입니다(제품처럼 계속 개선)

이 태도가 도구(41·42·46)에 생명을 줍니다.
