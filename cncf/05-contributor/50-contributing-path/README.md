# 50 — 기여의 길: 소비자에서 구성원으로

> 커리큘럼의 마지막 모듈이자, 이 커리큘럼 전체의 목적지입니다. 50개 모듈에서 쌓은 지식 — 지형(01~10), 프로젝트 내부(11~45), 조립·판단(46~48), 거버넌스(49) — 은 모두 이 순간을 위한 것이었습니다: **CNCF 생태계에 실제로 기여하는 것.** 이 모듈은 기여 대상을 고르는 법(49의 정찰 활용), 첫 기여를 찾는 법(good first issue·CLOTributor), 코드 밖 기여(문서·이슈 트리아지·재현·번역·리뷰)의 가치, PR의 예절과 기술, 멘토링 프로그램(LFX), KubeCon·커뮤니티 활동, 그리고 지속 가능한 기여자로 성장하는 길(contributor ladder 오르기)을 다룹니다. 자격증이 아니라 **기여 이력**이 이 커리큘럼의 졸업장입니다.

## 학습 목표

1. 기여 대상 프로젝트를 고르는 기준(관심×역량×거버넌스 건강)을 세웁니다
2. 첫 기여를 찾는 도구(good first issue·CLOTributor)와 방법을 압니다
3. 코드 밖 기여(문서·트리아지·재현·리뷰)의 가치와 방법을 압니다
4. 좋은 이슈·PR의 기술(재현·범위·소통 예절)을 익힙니다
5. 멘토링(LFX)·커뮤니티(KubeCon·SIG/TAG)·ladder로 지속 성장하는 길을 압니다
