# 학습 가이드 — 흩어짐과의 싸움

## 문제부터 — 규모가 만든 혼돈

24(마이크로서비스)에서 서비스가 수백 개로 늘 때의 통신 문제를 봤습니다. 하지만 규모는 다른 문제도 만듭니다 — **발견성(discoverability)과 인지 부하**:

```
서비스 300개인 조직의 신입 개발자 질문:
  "결제 서비스는 누가 담당하지?"          → 슬랙으로 수소문
  "이 API는 어디에 문서가 있지?"          → 위키? README? 노션?
  "새 서비스를 만들려면 뭘 설정하지?"      → 다른 서비스 복붙 + 물어보기
  "이 서비스는 어느 클러스터에 떴지?"      → kubectl 여기저기
  "누가 이 라이브러리를 쓰고 있지?"        → 알 수 없음
→ 지식이 사람 머리·흩어진 도구에 분산 → 매번 재발견
```

이것이 Backstage가 푸는 문제입니다 — **흩어진 것을 하나의 포털로 모아 발견 가능하게** 합니다.

## Backstage의 답 — 세 기둥

```
① Software Catalog (소프트웨어 카탈로그)
   모든 서비스·API·리소스를 한 목록에
   각 항목: 소유자·문서·배포처·의존관계
   → "무엇이 있고 누구 것인가"의 단일 출처

② Software Templates (소프트웨어 템플릿, Scaffolder)
   "새 서비스 만들기" 버튼 → 황금 경로로 스캐폴딩
   레포 생성 + CI 설정 + 카탈로그 등록 + 인프라(41) 프로비저닝
   → "새로 시작"의 표준화

③ TechDocs (기술 문서)
   문서를 코드 옆(레포)에 Markdown으로 → 포털에서 렌더
   → "문서가 코드와 함께 산다" (docs-as-code)
```

여기에 **플러그인**이 얹힙니다 — CI 상태, 쿠버네티스 배포, 모니터링(Grafana), 취약점(보안) 등을 각 서비스 페이지에 통합합니다.

## 41과의 짝 — 백엔드와 프런트

```
41 Crossplane: 셀프서비스 인프라의 API (백엔드)
  개발자가 AppDatabase Claim을 만들면 인프라 생성
42 Backstage: 그 API를 감싸는 포털 (프런트)
  개발자가 "PostgreSQL 추가" 버튼 → 뒤에서 Crossplane Claim 생성

→ Backstage(UI) + Crossplane(API) = 완전한 셀프서비스
  개발자는 YAML도 kubectl도 몰라도 포털에서 클릭
```

이 짝이 47(플랫폼 엔지니어링)의 핵심 — 플랫폼 팀은 API(41)와 그 포털(42)을 제공하고, 개발자는 셀프서비스합니다.

## 오해 방지 — Backstage는 "또 하나의 위키"가 아닙니다

```
위키/포털의 흔한 실패: 만들어놓고 아무도 안 씀 (금세 낡음)
Backstage의 다른 점:
  카탈로그가 코드(catalog-info.yaml)에서 자동 수집 → 낡지 않음
  개발자가 실제 일(새 서비스·문서·배포 확인)을 하는 곳 → 살아있음
  단, ★ "그냥 깔면 되는" 것이 아니라 조직의 참여·관리가 필수 (pitfalls)
```

## 이 모듈의 관점 — 도구가 아니라 문화

Backstage는 기술이지만, 그 성패는 **조직 문화**에 달렸습니다:
- 카탈로그가 정확하려면 팀들이 `catalog-info.yaml`을 관리해야
- 템플릿이 쓰이려면 플랫폼 팀이 좋은 황금 경로를 만들어야
- 이는 47(플랫폼 엔지니어링)의 "제품으로서의 플랫폼(platform as a product)" 사고와 직결

그래서 이 모듈은 Backstage의 기능을 배우되, 그것이 **왜 조직 차원의 노력**인지를 함께 봅니다. 도구만 깔면 실패합니다(pitfalls의 사고 사례).

## CNCF 맥락

Backstage는 CNCF **Incubating**(2024년 기준)에서 널리 쓰이는 개발자 포털의 사실상 표준입니다. 스포티파이가 내부 도구로 만들어 오픈소스화·기증했습니다 — 08의 "실전에서 태어난 도구"의 또 다른 예입니다. 다만 뒤에서 볼 것처럼 도입·운영 비용이 상당해, "관리형 Backstage"(Roadie·Spotify Portal 등) 시장도 생겼습니다.
