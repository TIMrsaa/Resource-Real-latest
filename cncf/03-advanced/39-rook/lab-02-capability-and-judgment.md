## Step 4. 도입 판단 — Rook-Ceph vs 대안

```bash
cat <<'EOF'
=== 언제 Rook-Ceph인가 (theory §6) ===

Rook-Ceph가 맞는 경우:
  ✅ 온프레미스 (관리형 없음 — 05의 자체 운영 조건)
  ✅ 통합 스토리지 (블록+파일+오브젝트를 하나로)
  ✅ 대규모 (Ceph의 확장성)
  ✅ + Ceph·분산 시스템 운영 역량

대안:
  클라우드 → EBS·EFS·S3 (관리형, 05)
  단순 블록만 → Longhorn (05 — 더 가벼움, Rancher)
  파일만 → 관리형 NFS 또는 CephFS
  오브젝트만 → MinIO(단순) 또는 S3

판단 순서 (05·09):
  1. 클라우드면 관리형 우선
  2. 온프레면 요구가 통합(블록+파일+오브젝트)인가요?
     Yes → Rook-Ceph
     단순 블록 → Longhorn
  3. Ceph 운영 역량이 있는가요? (없으면 무게 감당 못 함)
EOF
```
