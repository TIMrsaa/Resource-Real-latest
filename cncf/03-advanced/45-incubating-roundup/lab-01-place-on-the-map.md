# Lab 01 — 프로젝트를 지도에 놓기

> 도구 실습이 아니라 **항해술 훈련**입니다. 여러 프로젝트를 주고, 05·01~10에서 배운 축과 advanced에서 배운 프로젝트에 연결해 스스로 지도에 놓는 연습을 합니다. 답을 보기 전에 직접 해보는 것이 핵심입니다.

## 연습 방법

각 프로젝트에 대해 다음을 채웁니다(먼저 스스로, 그다음 답 확인):

```
프로젝트: ________
1. 축(01~10): ________ (관측/네트워크/스토리지/보안/런타임/플랫폼/멀티클러스터)
2. 연결: 이미 배운 ______의 대안/보완/확장
3. 존재 이유: ______을 좁혀/다르게 풉니다
4. 성숙도 감(추정): Sandbox/Incubating/Graduated
```

## 문제 세트 A — 관측

**A1. Thanos**
<details><summary>답</summary>

**A2. Loki**
<details><summary>답</summary>

- 성숙도: 널리 채택 (Grafana 생태계)
</details>

**A3. OpenCost**
<details><summary>답</summary>

- 성숙도: Incubating
</details>

## 핵심 훈련 포인트

```
모든 답의 공통 구조:
  "이건 [축]의, [이미 배운 것]의 [대안/확장]이고, [무엇]을 [좁혀/다르게] 푼다"

이 문장을 채울 수 있으면 = 지도에 놓은 것
채우지 못하면 = 더 조사할 방향을 안 것 (그것도 성과)

★ 프로젝트 이름을 외우는 게 아니라, 이 문장 틀로
  어떤 새 프로젝트든 위치시키는 근육을 기릅니다 (05의 항해술)
```

## 정리

- 항해술 = 축 식별 + 이미 아는 것에 연결 + 존재 이유(무엇을 좁혔나)
- 관측(Thanos·Loki·OpenCost)은 11의 확장, 네트워크(Submariner·Karmada)는 멀티클러스터
- 보안(in-toto·Kubescape)은 cicd 21·31·32, 워크로드(Volcano)는 08의 특화
- **★ "[축]의 [아는 것]의 [대안], [무엇]을 [좁혀] 푼다" 문장을 채우면 지도에 놓은 것**
