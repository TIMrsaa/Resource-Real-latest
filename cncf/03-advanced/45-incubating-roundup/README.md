# 45 — Incubating 라운드업: 지형의 나머지를 채우입니다

> advanced 트랙(22~44)에서 Graduated·주요 Incubating 프로젝트를 깊게 팠습니다. 하지만 CNCF 지형(01~10에서 배운 랜드스케이프)에는 아직 이름만 스친 중요한 Incubating·Sandbox 프로젝트가 많습니다. 이 모듈은 그것들을 **범주별로 묶어** 빠르게 훑되, 각각을 "어느 축(01~10의 지형)에 속하고, 이미 배운 무엇과 관계되며, 언제 쓰나"로 자리매김합니다. 목표는 깊이가 아니라 **지도 완성** — 새 프로젝트를 만났을 때 "아, 이건 OO 축의 OO 대안이구나"로 즉시 위치시키는 능력입니다. 이것이 05(계속 늘어나는 랜드스케이프를 항해하는 법)의 실전이고, contributor(49~50)로 가기 전 지형의 마지막 정리입니다.

## 학습 목표

1. advanced에서 안 다룬 주요 Incubating 프로젝트를 범주별로 자리매김합니다
2. 각 프로젝트를 "01~10의 어느 축 + 이미 배운 무엇의 대안·보완"으로 위치시킵니다
3. 새 프로젝트를 만났을 때 스스로 지도에 놓는 방법(05의 항해술)을 체득합니다
4. Sandbox→Incubating→Graduated 성숙도와 채택 판단(08)을 종합합니다
5. 이 커리큘럼이 다룬 것과 안 다룬 것의 경계를 알고, 계속 배우는 법을 압니다

## 선행: 01~10(랜드스케이프 지형 — 필수), advanced 전체(22~44) · 도구: 없음(정리·항해술 중심)
