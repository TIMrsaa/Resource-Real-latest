# 45 — 첫 PR: 업스트림에 이름을 남깁니다

> 졸업 모듈. 41(빌드)·42(코드 지도)·43(커뮤니티/CLA)·44(테스트)를 전부 장전했습니다 — 이제 실제로 이슈를 잡고, 고치고, PR을 보내고, 리뷰에 응답해 **머지까지** 갑니다. 이 모듈의 lab은 따라 치는 실습이 아니라 **실전 운영 절차서**입니다.

## 학습 목표

1. 잡을 만한 이슈를 고르는 눈(난이도/선점/SIG)을 갖춥니다
2. fork→branch→수정→테스트→커밋 규약→PR 제출의 전 과정을 수행합니다
3. prow 봇/리뷰어와의 상호작용(라벨, /retest, 리뷰 응답)을 처리합니다
4. 거절/방치/수정 요구 각각의 시나리오에 대응합니다
5. 첫 머지 이후의 성장 경로(두 번째 기여, org 멤버십)를 압니다
