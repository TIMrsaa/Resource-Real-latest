# 용어 사전 (가나다순)

> 모듈을 읽다 모르는 단어가 나오면 여기로. 한 줄 정의 + 비유.

| 용어 | 정의 | 비유 |
|------|------|------|
| **노드(Node)** | 클러스터를 구성하는 컴퓨터 1대 (VM/물리서버) | 사무실 건물 1개 |
| **네임스페이스(Namespace)** | 클러스터 안의 논리적 칸막이 | 회사의 부서 |
| **디플로이먼트(Deployment)** | Pod 복제본 수 유지 + 롤링업데이트를 담당하는 컨트롤러 | "그 팀 항상 3개 유지" 인사규정 |
| **라벨(Label)** | 리소스에 붙이는 key=value 이름표. 모든 연결의 기준 | 직원 명찰 |
| **레플리카셋(ReplicaSet)** | Pod 개수를 정확히 유지하는 컨트롤러 (Deployment의 부하) | 인원수 점검 반장 |
| **매니페스트(Manifest)** | 리소스를 선언한 YAML/JSON 파일 | 주문서 |
| **볼륨(Volume)** | Pod에 연결하는 저장 공간 | 팀 공용 캐비닛 |
| **서비스(Service)** | 변하는 Pod들 앞의 고정 접속 지점(가상 IP) | 부서 대표 전화번호 |
| **서비스어카운트(ServiceAccount)** | Pod(프로그램)용 신분증 | 사원증 (사람용은 User) |
| **셀렉터(Selector)** | 라벨로 대상을 찾는 조건식 | "명찰에 'web'이라 쓰인 사람 전부" |
| **스케줄러(Scheduler)** | 새 Pod를 어느 노드에 둘지 결정하는 컴포넌트 | 인사 배치 담당자 |
| **시크릿(Secret)** | 비밀번호/키 등 민감 정보 저장 객체 | 금고 (단, 기본은 base64 — 자물쇠 아님 주의) |
| **어드미션(Admission)** | API 요청이 저장되기 전 검사/수정하는 관문 | 결재 라인 |
| **에드센드포인트슬라이스(EndpointSlice)** | Service 뒤 실제 Pod IP 목록 | 대표번호의 내선 연결표 |
| **오퍼레이터(Operator)** | CRD + 컨트롤러로 운영 지식을 자동화한 것 | 분야 전문 자동화 로봇 직원 |
| **인그레스(Ingress)** | HTTP(S) 외부 트래픽 라우팅 규칙 (유지보수 모드, 후계자: Gateway API) | 건물 안내데스크 |
| **체이오에스(CRD, CustomResourceDefinition)** | 사용자 정의 리소스 타입 등록 | 새 주문서 양식 등록 |
| **컨테이너(Container)** | 격리된 환경에서 실행되는 프로세스 + 그 파일시스템 | 1인용 작업 부스 |
| **컨트롤 플레인(Control Plane)** | API서버/etcd/스케줄러/컨트롤러매니저 — 클러스터의 두뇌 | 본사 경영진 |
| **컨트롤러(Controller)** | "현재 상태 → 원하는 상태" 조정 루프를 도는 프로그램 | 온도 맞추는 에어컨 |
| **컨피그맵(ConfigMap)** | 설정값 저장 객체 | 게시판의 업무 지침서 |
| **쿠브렛(kubelet)** | 각 노드에서 Pod 실행을 책임지는 에이전트 | 건물 관리소장 |
| **쿠브 프록시(kube-proxy)** | Service 가상 IP를 실제 Pod로 연결하는 네트워크 규칙 관리자 | 전화 교환원 |
| **테인트/톨러레이션(Taint/Toleration)** | 노드가 Pod를 밀어내는 표시 / 그걸 견디는 허가 | "관계자 외 출입금지" / 출입증 |
| **파드(Pod)** | 같이 배치되는 컨테이너 묶음. K8s 최소 배포 단위 | 같은 방을 쓰는 팀 |
| **퍼시스턴트볼륨(PV/PVC)** | 클러스터 저장소(PV)와 그 사용 신청서(PVC) | 창고와 창고 사용 신청서 |
| **프로브(Probe)** | 컨테이너 생존/준비 상태 검사 | 정기 건강검진 |
| **헬름(Helm)** | K8s 패키지 매니저 (차트 = 패키지) | 앱스토어 + 설치 마법사 |
| **etcd** | 클러스터의 모든 상태를 저장하는 분산 키-값 DB | 본사 금고 (유일한 진실 원본) |
| **HPA** | 부하에 따라 Pod 수를 자동 조절 | 손님 많으면 알바 더 부르기 |
| **kubectl** | K8s API를 호출하는 공식 CLI | 본사와 통화하는 전화기 |
| **OCI** | 컨테이너 이미지/런타임 표준 규격 | 화물 컨테이너의 국제 규격 |
| **StatefulSet** | 고유 ID와 저장소를 가지는 Pod 집합 (DB용) | 지정 좌석 + 개인 사물함 직원 |

> 이 표는 모듈이 추가될 때마다 갱신됩니다.
